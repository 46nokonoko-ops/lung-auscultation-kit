# 聴診トレーナー

肺音と心音を、聴診部位ごとに音を割り当ててシミュレーションする臨床OSCE対策アプリ。

- **肺音** — 両肺を4分画（右上・右下・左上・左下）
- **心音** — 4領域（大動脈弁・肺動脈弁・三尖弁・僧帽弁）。うち三尖弁は音源未収録

画面右上で肺音／心音を切り替える。

PWA として作ってあるので、ブラウザの「ホーム画面に追加」でアプリとして使えます。
一度開けば音源ごとキャッシュされ、**オフラインでも動きます**。

## 起動

ローカルで動かす場合は Service Worker の都合でサーバ経由が必要です：

```bash
python3 "/Users/nokonoko/Desktop/claude code/lung-auscultation-kit/serve.py"
```

→ ブラウザで http://127.0.0.1:8742

（`index.html` を直接ダブルクリックしても動きますが、その場合オフライン機能は無効です）

## 使い方

**練習モード**
- 病態プリセット（11種）を選ぶと4区画に所見が自動配置され、解説が表示される
- 区画ごとのプルダウンで自由に組み合わせてカスタム所見も作れる
- 区画をクリック（またはキー `1`〜`4`）で聴診、`Esc` で停止。同時に鳴るのは1区画だけ

**出題モード**
- モードを開いた時点で自動的に1問出題される
- 出題形式は「病態シナリオから出題」／「ランダム配置」／「共有コードから出題」の3つ
- 配置は伏せられるので、各区画を聴いて音を選び、想定病態も答えて採点
- 正解数は累積表示される

**作問・共有モード**
- 4区画に肺音を設定し、`LUNG1-…` という共有コードを発行する（病態の正解も任意で埋め込める）
- コードをLINE等で送れば、相手は「出題モード」→「共有コードから出題」に貼るだけで解答できる
- 「練習モードの配置を読み込む」「ランダムに埋める」で作問を省力化できる
- 相手にもキットのフォルダ一式が必要（音源が入っているため）
- コードは50〜60字程度。`index.html#q=LUNG1-…` の形でURLに付けて開くこともできる（サーバに置いた場合）
- コードに入るのは配置と病態だけ。復号可能な形式なのでカンニング防止にはならない

## 音源

`sounds/` に格納（Downloads 内の既存ファイルを複製）。

| ファイル | 用途 |
|---|---|
| `normal.mp4` | 正常呼吸音／呼吸音減弱（音量を下げて使用） |
| `normal_alt.mp3` | 正常呼吸音（別ソース・予備） |
| `wheeze.mp4` | wheezes（笛音） |
| `wheeze_copd.mp3` | wheezes（COPD・呼気延長） |
| `rhonchi.mp4` | rhonchi（いびき音） |
| `fine_crackles.mp4` | fine crackles（捻髪音） |
| `coarse_crackles.mp4` | coarse crackles（水泡音） |

「呼吸音消失」は無音として扱う（音源不要）。

未収録：stridor、胸膜摩擦音、気管支呼吸音化。音源を `sounds/` に置き、`index.html` の `SOUNDS` に1行追加すれば選択肢に増やせる。

教育目的の個人利用を想定。

## ファイル構成

| パス | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JS 一体） |
| `manifest.json` | PWA 設定。アプリ名・アイコン・全画面表示 |
| `sw.js` | Service Worker。音源を含めてキャッシュしオフライン対応 |
| `icons/` | ホーム画面用アイコン（192/512/maskable/apple-touch） |
| `sounds/lung/` | 肺音の音源 |
| `sounds/heart/` | 心音の音源（12秒にトリミング済み） |
| `ATTRIBUTION.md` | 心音音源の出典とライセンス |
| `tools-trim-heart.py` | 心音の原本を12秒ループ用に切り出すスクリプト |
| `serve.py` | ローカル確認用の簡易サーバ |

`index.html` や音源を更新したら、`sw.js` の `CACHE` の版数（`lung-trainer-v1`）を上げてください。
上げないと、既に開いたことのある端末で古いキャッシュが表示され続けます。

## 公開について

GitHub Pages で配信する想定です。パスはすべて相対で書いてあるので、
`https://<ユーザー名>.github.io/<リポジトリ名>/` のようなサブパス配信でもそのまま動きます。

音源は第三者が教育目的で公開している録音です。リポジトリを public にすると
再配布にあたる点に注意してください。

## 心音について

**音源** — University of Michigan Medical School の Heart Sound & Murmur Library
（Richard D. Judge, M.D. / Rajesh Mangrulkar, M.D.）。**CC BY-SA 3.0** なので再配布可能。
詳細は [ATTRIBUTION.md](ATTRIBUTION.md)。

原本は各60秒超・計25MBあるため、`tools-trim-heart.py` で心周期を検出し、
拡張期（S2 の後の静かな区間）を始点・終点として**整数周期ぶんだけ**切り出している。
これによりループ再生しても拍が途切れない。合計2.3MB。

**部位ごとに選択肢が異なる** — 録音が聴診部位別に用意されているため、
大動脈弁領域4種・肺動脈弁領域5種・僧帽弁領域13種と、部位ごとに選べる音が違う。
出題の選択肢もその部位のものだけに絞られる。

**三尖弁領域** — 配布元に録音がないため、図には表示するが聴診できない（「未収録」と表示）。

## 共有コードの形式

- 肺音： `LUNG1-…`
- 心音： `HART1-…`

コードの接頭辞に種類が入っているので、受け取った側は自動で切り替わる。
URL末尾に `#q=コード` を付ければ、開いた瞬間にその問題が始まる。
